# Product photography

26 optimized WebP files represent 13 distinct generic produce entries. Each has a 360 px thumbnail and a maximum 1000 px detail. Exact source/artist/public-domain or CC0 license, original/derived file hashes, target product ID and review notes are in packages/catalogue/media.json. NOTICE.txt and docs/licenses/product-photography.txt carry credits.

377 catalogue entries remain pending exact photography. Generic photos are not reused for named cultivars or branded packs. One carrot candidate was rejected. No competitor screenshot assets, AI packaging, logo or promotional images are included.

Admin local uploads are stored independently in IndexedDB and need explicit owner review. They do not modify these bundled files or synchronize across apps.
