# GROZO customer website

Implemented Stage 2 React/TypeScript/Tailwind development interface. Run pnpm dev:web from the project root; build with pnpm --filter @grozo/web build. It uses labelled synthetic local data and no provider keys. Live mode fails closed until the Stage 3 backend exists. See [setup](../../docs/setup.md) and [features](../../docs/stage-2-features.md).
