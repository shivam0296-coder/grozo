# GROZO customer Android application

Implemented Kotlin/Compose/Material 3 development app. Open the parent apps/android workspace in Android Studio and select the customer module. Build :customer:assembleDebug; tested application ID com.grozo.customer.dev, min API 26, target API 36. Local Room records are synthetic; no OTP, payment, Maps or notification key is needed. See [build report](../../../docs/stage-2-build.md).
