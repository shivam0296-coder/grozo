# GROZO delivery partner Android application

Implemented Kotlin/Compose delivery workflow with development registration, availability, accept/decline, pickup, simulated collection/completion, history and derived development earnings. Open the parent apps/android workspace and select rider; build :rider:assembleDebug. Application ID com.grozo.rider.dev. No real location tracking, contact, payment or push is active.
