# ADR 0003 — Stage 3 redesign and catalogue tools

Accepted 2026-10-30 under the owner's explicit Stage 3 brief.

The requested Stage 3 is a redesign/catalogue enhancement of the current architecture. Preserve all commerce rules, original branding and working routes. Earlier roadmap backend work is deferred, not silently claimed done.

Only the brief is attached; product/classification PDFs and visual references are missing. Build independent layout and management functionality while marking source counts, final hierarchy and all exact images pending. Do not invent products, packaging, categories from examples or licensed-photo claims. Retain the clearly synthetic Stage 2 fixtures in their isolated directory.

Use optional product metadata and additive local state migration, not resets. Use atomic validated CSV batches with explicit duplicate retention. Store optimized local images in IndexedDB and audit metadata in the development workspace. Owner-reviewed is an attestation state, not automatic verification. Secure server media/identity is still a future trust boundary.

Keep original SQL/API contracts unchanged and add versioned extension drafts. No database is executed and no live route is asserted. Compile using the existing installed toolchain with --offline; no emulator, paid service or new dependencies are introduced.
