## Decisions and assumptions

ADR 0001 records the modular monolith, separate worker, integer-paise tax-inclusive money and threshold/cancellation interpretations. All paid/external integrations remain disabled. Zero-payable orders need an explicit no-charge fulfilment design before implementation; never submit a zero-amount Razorpay order.

## Files and resources

New project files are under this GROZO folder: documentation, source domain rules/tests, database designs, API contract, branding, reference seed, environment template and verification/package scripts. The neighboring research repository is preserved. GROZO is not yet a Git repository and has no commit or remote.

Stage 1 uses the installed Node runtime and short CPU-only local checks; no installed packages, dataset/model/media acquisition, GPU, cloud service or paid API use. Exact source/archive size and final check outcomes are recorded in validation.md. Existing machine memory inventory could not be read due to restricted system access; no capacity claim follows from this work.

## Security/privacy/data/license effects

No real customer/rider data, production secrets or payment details are used. The supplied owner contact details are not embedded into application fixtures. Product photos remain unacquired. Original material remains all rights reserved; no repository license change or third-party package adoption. Public official documentation was read for planning; no application data was sent to those services.
