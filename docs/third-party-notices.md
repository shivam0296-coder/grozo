# Third-party dependency and asset record

Original GROZO material remains all rights reserved; LICENSE has not been changed.

Web packages are pinned in package.json/pnpm-lock.yaml. Their installed declarations and provided notices are in docs/licenses/web-dependencies.json and web-notices.txt, also included as public/third-party-notices.txt in both web apps. The web dependency audit returned zero known advisories at this work cycle; this is not a security certification.

Android plugins/libraries are pinned and locked. Provided archive license/notice texts and resolved POM license declarations were collected into apps/android/core/src/main/assets/third-party-notices.txt and docs/licenses/android-dependencies.json. The collection includes build/test artifacts as well as app libraries; it is a provenance inventory, not a full legal/vulnerability certification. Gradle wrapper files are generated by the official verified Gradle distribution and retain its license.

The JDK/Android SDK/Gradle toolchains are used locally and are not redistributed in the source ZIP. Only the necessary Android SDK license was accepted during the owner-approved minimal setup; unrelated optional package licenses were skipped. No emulator or paid service was installed.

Product/category/hero illustrations are original source-native drawings. The 18 product records, addresses, riders, campaigns, coupons and orders are synthetic development fixtures. No competitor image, copied proprietary screen, real customer/rider record or model artifact is included. Screenshot captures show the development UI and may include records created by UI tests.

No private debug/release key, .env secret, credential file or service-account JSON belongs in the source archive. Retain upstream notices if redistributing components, and review all applicable terms and production/legal requirements before a commercial release.
